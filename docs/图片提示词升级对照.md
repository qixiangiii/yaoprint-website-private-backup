# 官网图片提示词库 · 系统性升级对照（v2）

> **优化对象**：`docs/图片生成提示词库.md` 全部 10 条提示词
> **体检维度**：① 目标是否明确 ② 表达是否清晰 ③ 约束是否完整 ④ 上下文是否适配 ⑤ 结果是否可验收
> **边界**：主题、主体、站内位置一律不动，只把"能看懂"改成"能出图、能验收、能成套"

---

## 0. 先看结论：10 条共有的 10 类缺陷

| # | 缺陷 | 命中位置 | 造成的后果 |
|---|---|---|---|
| 1 | **没有负面词，还主动"招"文字** | 第 5 条"白板画坐标系和草图"、第 6 条"标签清晰"、第 7 条"浮雕书签"、第 10 条控制屏 | AI 硬造文字必乱码，中文尤其严重，图直接不可用 |
| 2 | **品牌色只给"天空蓝"，无 HEX、无占比** | 全部 10 条 | 每张蓝都不一样，10 张放一起不成套；实测品牌色是 `#1287C6` |
| 3 | **没有镜头语言** | 全部，只写"浅景深/广角/特写" | 缺焦段、光圈、机位、透视 → 尺度关系随机，成品像两种风格的图 |
| 4 | **人物不可控** | 第 1/2/5/8/9 条 | 人数、年龄、校服样式（易生成日韩制服或欧美校服）、是否看镜头全部随机 |
| 5 | **质感后缀自相矛盾** | 8 条"官网宣传照质感"、2 条"产品摄影质感"、1 条"艺术馆氛围" | 文案说要统一基调，条目自己破坏了统一 |
| 6 | **抽象形容词不可执行** | "动感与专注并存""明亮通透""温馨""科技感""艺术馆氛围" | 模型无法翻译成像素，等于没写 |
| 7 | **浅景深滥用** | 第 5/6/8/10 条 | 课堂、货架、车间、全景的核心信息是"空间里有啥"，虚掉就失去意义，与目标冲突 |
| 8 | **唯一 hero 图缺叠字安全区** | 第 8 条（`explore.html` 主视觉） | 见下方 0.2 第 1 条：左侧要叠深色渐变 + 白字，原提示词完全没提，必然糊成一片 |
| 9 | **没有验收标准** | 全文 | 生成后凭什么判断"这条过了"没写，只能凭感觉重试 |
| 10 | **没有一致性机制** | "复用技巧"说"只改名词即可" | 改名词会连带改掉光线与配色，10 张图无法收敛成一个系列 |

## 0.1 可直接复用的两块积木

优化后的每条提示词都由 **「场景段 + 技术段 + 排除段」** 三段拼成，其中两段是共通积木，写一次、每条复用：

**统一风格锚（S）**
```
写实纪实摄影，全画幅机身 + 定焦镜头，自然光为主、阴影柔和，中性偏冷色调；
品牌天空蓝 #1287C6 仅作点缀（占画面 8–15%，落在墙面/柜体/坐垫/线材等 1–2 处），
环境色为浅灰 + 浅木；真实材质细节（PLA 层纹、哑光塑料、织物褶皱），轻微胶片颗粒，
非 CG 渲染、非插画、非 3D 效果图
```

**统一排除词（N）**
```
排除：画面内任何文字、汉字、英文、数字、公式、logo、品牌标识、水印、边框、字幕条；
多余手指、六指、融合肢体、畸形手部、扭曲面部；塑料感皮肤、过度磨皮、HDR 过曝、
鱼眼畸变、大面积纯蓝墙；人物直视镜头摆拍（保持纪实旁观视角）
```

## 0.2 三条与站点样式绑定的硬约束（读 `public/css/style.css` 实测得出）

1. **hero 图左侧 45% 必须是"中低调 + 低信息"区域。**
   `.hero-overlay::before` 在文字底下压了 `linear-gradient(90deg, rgba(16,26,36,.72) 0%, .44 38%, .08 68%, transparent 90%)`。
   含义：左侧越亮、越满，叠上的白字越糊；左侧留空且色调偏暗，白字才立得住。
2. **3:2 源图用于 hero 会被裁掉上下约 20–25%。**
   `.hero-img{object-fit:cover}` + `.hero-slide{height:70vh; max-height:760px}`，1440×700 视口下实际比例约 2:1。
   含义：**主体必须落在画面垂直中部 60% 内**，否则头顶或地面被切。
3. **"天空蓝"要落到 `#1287C6`（logo 描边色），h1 高亮用的是 `#63B4E7`。**
   含义：提示词里写死 HEX，并限定占比 8–15%，10 张图才能拼成一套。

## 1. 教育 · 创客教室

**站内位置**：`public/img/scenes/education.jpg`

**原文**
> 写实摄影：明亮的现代中国中学创客教室里，一群穿校服的中学生围在几台桌面3D打印机旁协作，一位年轻老师在旁边俯身指导，桌面摆放着刚打印好的齿轮和桥梁模型，天空蓝色点缀的墙面，自然光透过大窗洒入，浅景深，官网宣传照质感，高清

**诊断**
- "一群"没有人数，成图里可能是 3 人也可能是 20 人；"穿校服"没有样式，大概率生成日韩制服或欧美 blazer。
- "围在打印机旁协作"是状态不是动作 —— 模型只能画出手的乱团，手部畸形率极高。
- "几台"未定量，无法保证"设备充足"这个隐含的商业信息。
- 墙面"天空蓝色点缀"没有色值与面积，容易生成一整面蓝墙（与品牌"点缀"定位相反）。

**优化后**
```
写实纪实摄影，中国公立中学创客教室，中景。8 名 13–15 岁学生（4 男 4 女），
统一穿深藏青 + 白色运动式校服；左侧两名学生正在一台已打开舱门的桌面 3D 打印机前取件，
一人用镊子夹起刚打印好的齿轮，另一人手持桁架桥梁模型比对；右侧一名 25 岁左右女教师
穿浅色衬衫，俯身指点笔记本电脑屏幕上的建模界面；环境为浅灰墙面、白色长桌、
天空蓝 #1287C6 的工具柜与线材架各一处，墙上无任何标语与文字；下午自然光从画面
左后方落地窗斜射（5000K），地面有柔和长影；35mm 镜头 f/2.8，机位与学生视线齐平，
浅景深但背景仍可辨空间；主体集中在中右部，画面左侧 1/3 是较空的中低调墙面与窗光；
（＋S ＋N）
```

**主要改进点**
- 人数、年龄、校服样式、教师年龄与服装全部锚定 → 与其他含学生图统一成"同一所学校"。
- 把"协作"翻译成两个具体手部动作（夹齿轮 / 递模型），这是压手部畸形最有效的手段。
- 补左侧 1/3 留白，同一张图既能当卡片也能临时顶 hero 位。
- "天空蓝墙面"改为"两处柜体 + 线材架"并写死 `#1287C6`，扣住"点缀不铺满"。

## 2. DIY · 个人创作

**站内位置**：`public/img/scenes/diy.jpg`

**原文**
> 写实摄影：温馨的个人工作台家庭书房，一位初中生独自坐在桌前用笔记本电脑进行3D建模，旁边一台小型桌面3D打印机正在打印一个创意小模型，台灯暖光与窗外自然光结合，天空蓝色调点缀，浅景深，官网宣传照质感，高清

**诊断**
- "台灯暖光 + 窗外自然光"是两个相反色温硬凑，成图必脏（一侧橙一侧蓝），且与"中性偏冷"的统一基调冲突。
- "创意小模型"是空概念，模型会随机生成一个说不出是什么的东西。
- "温馨"不可执行；"家庭书房"没有地域锚点，默认出欧美风。
- 缺少年级、性别、桌面道具，画面信息密度不够，撑不起"个人创作"的卖点。

**优化后**
```
写实纪实摄影，中国城市家庭书房一角，中近景。一名 14 岁男生穿灰色卫衣坐在浅木书桌前，
用笔记本电脑做 3D 建模，屏幕内是对称造型的手机支架三维模型（线框视图，无文字）；
右手握鼠标、左手托腮思考；书桌右侧一台小型封闭式桌面 3D 打印机，舱内指示灯亮着，
正在打印同款支架的半成品，可见细密层纹；桌面散落游标卡尺、半卷 PLA 线材、
两张无字草图纸；背景为白色书架、绿植、窗外傍晚偏冷的暮色；主光为桌面 LED 台灯的
柔和定向光（5600K，不用暖黄钨丝灯），窗光作轮廓光；50mm 镜头 f/2.0，机位略高于桌面
俯拍 15°，浅景深；天空蓝 #1287C6 只出现在鼠标垫与线材卷标签；画面右侧 1/3 较空；
（＋S ＋N）
```

**主要改进点**
- 把打架的双色温改为"5600K 主光 + 窗光轮廓光"，保留"暖意"的观感但去掉脏色。
- "创意小模型"落到"手机支架"，与课程第 7 课时「手机支架设计师」呼应，图能当课件用。
- 补游标卡尺等道具锚点，让"建模 → 测量 → 打印"的链路在画面里自洽。
- 屏幕内容显式"无文字"，避免 AI 在 UI 上生成乱码。

## 3. 实用 · 生活收纳件

**站内位置**：`public/img/scenes/utility.jpg`

**原文**
> 写实摄影：整洁桌面上整齐排列着多件实用的3D打印家居收纳件特写——线缆整理器、桌面笔筒、手机支架、挂钩、收纳盒，多彩PLA材质质感，柔和的天空蓝背景与自然光，浅景深，产品摄影质感，高清

**诊断**
- "特写"与"多件平铺"是两种互斥构图，模型只能二选一，结果往往是五件挤成一团。
- "多彩"直接推翻统一基调；五种高饱色摆一起会显得像廉价玩具，削弱"实用件"的专业感。
- "多件"未给件数、尺寸、排布方向，投影方向也可能互相打架。
- 没有任何材质细节要求，成图常是光溜溜的塑料块，看不到"这是打印出来的"。

**优化后**
```
写实产品静物摄影，45° 俯视平铺构图。浅灰哑光桌面上从左到右等距一字排开 5 件 3D 打印
家居件：双槽线缆整理器（纯白）、圆柱笔筒（#1287C6）、可折叠手机支架（浅灰）、
承重挂钩（纯白）、带盖小收纳盒（半透明琥珀色 PETG）；每件可见规整的打印层纹与轻微接缝，
边缘干净、无拉丝、无支撑残留；背景是虚化的浅灰墙面与一株绿植，右后方一束柔和侧光
（5600K）投出方向一致的长而淡的投影；85mm 微距 f/4，画面水平、五件高度一致、
等距对齐；构图居中，四周留 8% 净空，顶部 15% 保持简洁；真实材质，非 CG 渲染
```

**主要改进点**
- 件数、顺序、颜色、材质逐项写死，把"多件"从随机变成可控的平铺矩阵。
- 五色收敛为「白 / `#1287C6` / 浅灰 / 半透明」的品牌色系，去掉"多彩"。
- 把互斥的"特写"改为 45° 平铺 + 85mm 微距，既有细节又有全貌。
- 加入"层纹 / 无拉丝 / 无支撑残留"这类**可验收**判据，一眼能看出图是否合格。

## 4. 艺术 · 雕塑与时尚

**站内位置**：`public/img/scenes/art.jpg`

**原文**
> 写实摄影：展厅一角展示着3D打印的艺术雕塑与时装配饰——几何花瓶、艺术灯罩、3D打印首饰和概念鞋履，柔和聚光灯，天空蓝与白色为主的极简展示空间，浅景深，艺术馆氛围，高清

**诊断**
- "展厅一角"里塞 4 类物件，模型会把它们糊成一堆，既没有主次也没有纵深。
- "概念鞋履"是高风险物体：3D 打印鞋的镂空结构极易生成结构崩坏件（断底、融脚）。
- 缺尺度参照，花瓶可能生成 10cm 也可能 2m；"艺术馆氛围"不可执行，常退化成空洞白屋。
- "柔和聚光灯"没给角度，"暗部"容易被压成死黑。

**优化后**
```
写实静物摄影，极简白色展厅一隅，低角度中景。视觉主体是一个直径 40cm 的 3D 打印镂空
几何花瓶（哑光白，Voronoi 蜂窝结构，层纹清晰），置于 70cm 高白色方形展台上，瓶内插
两支干枝；花瓶右后方虚化处是同一工艺的 3D 打印灯罩，透出柔和暖白光；展台左侧小托盘上
陈列 3 件 3D 打印几何首饰（耳环、戒指、胸针，哑光金与象牙白）；画面最右缘景深之外，
一个低矮展台上放着一只 3D 打印概念鞋，仅入画一半且明显虚化；背景纯白墙面，
中部一道窄的 #1287C6 色带作品牌呼应；一盏 45° 柔光聚光灯打在花瓶上，
投影干净、边缘柔和，暗部保留细节不过曝；50mm f/2.5，浅景深；主体居中偏右，左侧留白；
（＋S ＋N）
```

**主要改进点**
- 4 类物件重排成 3 层纵深（主体 / 侧后 / 右缘），画面有主次，不再糊成一团。
- 概念鞋保留时尚属性，但推到"右缘 + 景深外 + 只入一半"，即使结构有瑕疵也不影响成图。
- 补 40cm / 70cm 尺度参照，让比例关系可信。
- 聚光灯补角度并加"暗部保留细节"，防过曝与死黑。

## 5. 学院 · 课堂教学

**站内位置**：`public/img/cards/academy.jpg`（复用最广，也是 `support/academy.html` 的 hero）

**原文**
> 写实摄影：中国中学课堂里，老师站在白板前讲解3D打印与建模课程，白板上画着三维坐标系和零件草图，学生们认真听讲，桌面整齐摆放教材与3D打印教具，明亮通透，天空蓝点缀，官网宣传照质感，高清

**诊断**
- **最大风险**：要求白板上"画三维坐标系和零件草图" + 桌面"摆放教材"，等于点名要模型去写字，中文必然乱码，教书封面也必然糊字。这一条是 10 条里最容易整张报废的。
- "认真听讲"是心理状态不是姿态，模型只能画出一排僵硬的正面人像。
- 用浅景深却要交代"课堂"的空间信息，与目标自相矛盾。
- 该图同时被当 hero 用（`support/academy.html`，`min-height:380px`），却没留叠字位。

**优化后**
```
写实纪实摄影，中国公立中学教室，中景，侧后方机位。一名 30 岁左右男教师穿浅蓝衬衫
站在白板左侧，右手举起一个 3D 打印的齿轮模型讲解，左手自然下垂；白板上只用黑色马克笔
画了 3 个无标注的几何示意（立方体、圆柱、一个零件的分层剖面线），不出现任何文字、
公式、数字与箭头标注；前排 6 名 13–15 岁学生穿深藏青运动式校服：2 人抬头看白板，
1 人低头在笔记本上速写零件轮廓，其余自然侧脸，无人看镜头；桌面摆放打开的笔记本电脑、
无封面文字的白纸讲义、游标卡尺与两个 3D 打印小模型；教室为白色墙面、#1287C6 的
课桌边框与窗帘带；阴天漫射光从右侧高窗进入（5600K），整体明亮但无直射硬光；
35mm f/4，深景深保证前后排清晰；主体在中右部，左侧白板是较空的浅色面；右侧 1/3 留白；
（＋S ＋N）
```

**主要改进点**
- 白板内容从"坐标系 + 草图"改为"3 个无标注几何示意"，并显式禁文字 —— 从源头掐掉乱码。
- "教材"改为"无封面文字的白纸讲义"，避免整本书的乱码封面。
- 给教师一个可画的动作（举齿轮模型）+ 学生的三种具体姿态，替代"认真听讲"。
- 浅景深 → `f/4` 深景深（课堂的价值在环境信息），并按 hero 用途补左侧留白。

## 6. 耗材 · 线材管理

**站内位置**：`public/img/cards/filament.jpg`

**原文**
> 写实摄影：教室角落的3D打印材料管理区特写，货架上整齐码放各色PLA与ABS线材卷，天空蓝、白、橙、绿等颜色，标签清晰，旁边是几个线材收纳盒，自然光，浅景深，产品摄影质感，高清

**诊断**
- **"标签清晰"是本条最致命的四个字**：清晰标签 = 模型必须写字，中文标签几乎必定乱码，而且每卷都是标签，出错面积最大。
- 颜色"蓝、白、橙、绿"四色高饱，与品牌点缀色体系无关，也削弱"材料管理"的专业感。
- "特写"与"货架"尺度冲突；未给层数、卷数、盘径，排布无从约束。
- 浅景深会让三层货架只清一层，反而看不出"码放整齐"。

**优化后**
```
写实摄影，中学创客教室的耗材管理区，正面平视中景。三层浅木色开放式货架对称排布，
```

> 写实摄影：现代中学创客空间全景，开阔明亮的房间里有3D打印区、激光切割区、电子焊接区和讨论区，几组穿校服的学生分别在创作，天空蓝主色调墙面，落地窗自然光，广角，官网宣传照质感，高清

- **这条是全组唯一必须叠字的图，却完全没写叠字安全区。** 页面在左侧压了 72% 深的黑蓝渐变再放白色大标题，原提示词的"开阔明亮 + 天空蓝主色调墙面"恰好把左侧做成最亮最满的区域，白字必糊（见 0.2 第 1、2 条）。

```
构图硬约束：画面左侧 45% 由落地窗框、浅灰墙面与地面阴影构成，色调中低、无关键设备与
```

## 附录 A · 变量槽位表（改一处，不要改一片）

原文档"复用技巧"说"只改名词即可"，实测会连带改掉光线与配色。正确做法是只动槽位、锁定其余：

| 槽位 | 可替换值 | 必须保持不动的部分 |
|---|---|---|
| 年龄段 | 小学生 / 初中生 / 高中生 | 校服配色（深藏青 + 白）、人数区间、色温 5000–5600K、`#1287C6` 占比 |
| 材料 | PLA / PETG / 树脂 / 钛合金 | 层纹或粉末床等材质证据、光线方案、排除段 |
| 空间 | 创客教室 / 家庭书房 / 展厅 / 车间 | 三段结构（场景 + 技术 + 排除）、左侧或右侧留白规则 |
| 画幅 | 3:2（1536×1024）/ 1:1（1024×1024） | 焦段与光圈的**等效视觉**（换方形时把 35mm 提到 50mm，避免主体过大） |
| 品牌色 | `#1287C6` → 中性浅灰 + 木色 | 8–15% 点缀占比这条规则本身 |

## 附录 B · 生成后验收清单（8 项，逐条打勾）

1. **无字**：放大到 100% 扫一遍白板、标签、屏幕、书封、立牌，任何一个可读字符即不合格。
2. **手部**：数一遍所有人物的手指数量与关节走向，取件、握鼠标、举模型这三处重点看。
3. **蓝色**：目测 `#1287C6` 相关面积是否在 8–15%；出现大面积蓝墙即不合格。
4. **留白**：hero 图左侧 45% 是否中低调、无主体；卡片图顶部 15% 是否干净。
5. **裁切**：按 2:1 横切一次预览，主体是否仍在垂直中部 60% 内。
6. **水印区**：底部 8%（约 82px）是否无主体 —— 大于 58px 水印高度，裁完不伤画面。
7. **景深**：课堂 / 货架 / 车间 / 全景四类必须是深景深，前后信息都要能读。
8. **成套**：10 张缩略图并排看，色温、蓝的饱和度、颗粒感是否像同一天同一批人拍的。
